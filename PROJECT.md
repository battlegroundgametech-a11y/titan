# TITAN

## Overview

Titan is a premium crypto credit card platform built with Next.js, Tailwind CSS, RainbowKit, AWS, PostgreSQL, and Ethereum smart contracts.

The goal is to provide users with Virtual, Physical, and NFT-based crypto cards through a luxury, minimal, and secure web experience.

---

## Technology Stack

### Frontend

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- RainbowKit
- Wagmi
- Viem

### Backend

- Next.js API Routes
- AWS RDS PostgreSQL

### Infrastructure

- AWS EC2
- Node.js
- PM2
- Telegram Bot

### Blockchain

- Ethereum
- Sale Contract
- Vault Contract
- ERC-721 NFT Contract
